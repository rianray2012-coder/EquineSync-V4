# Master EquineSync Wave 2 Scope and Non-Goals

In scope: stable horse and facility identity, location hierarchy, assignment
history, daily-care evidence, task references, incidents, inventory, equipment,
maintenance, read-only operations projection, tenant isolation, audit,
idempotency, additive migration, rollback, and historical reconstruction.

Out of scope: contracts, lessons/training plans, billing/payments, payroll,
communications delivery, provider activation, external calendars, AI,
marketplace, public API, mobile publication, broad portal launch, production,
and Wave 3.
