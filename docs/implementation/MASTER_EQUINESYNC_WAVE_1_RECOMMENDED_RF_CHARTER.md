# Recommended Wave 1 RF Charter

## Proposed RF

`W1-RF01 IDENTITY FOUNDATION READINESS AND SECURITY HARDENING ASSESSMENT`

## Purpose

Produce executable planning evidence for the existing identity foundation before any runtime convergence or provider-transition decision.

## Authorized scope if later approved

- Read-only current-state inventory.
- Threat model and trust-boundary analysis.
- Canonical account/actor/source-of-truth mapping proposal.
- Role, platform-role, membership, barn/facility, relationship and permission matrix.
- Session, refresh, recovery, suspension and revocation contract review.
- Audit-attribution and observability gap analysis.
- Schema/index/migration inventory without mutation.
- Focused test-baseline execution and proposed regression plan.

## Explicit exclusions

No source-code edits, authentication changes, provider selection, credentials, schemas, indexes, migrations, seed execution, data mutation, permission changes, external activity, deployment, production or launch.

## Entry criteria

- Atlas adopted.
- Wave 0 locked.
- Identity V2.0 locked.
- Relevant constitutional dependencies identified.
- Founder approves this exact bounded RF.
- No unresolved P0.

The RF itself must complete the current implementation inventory, threat model, source-of-truth decision proposal, permission mapping, data/schema/migration assessment, rollback assessment, test plan and observability plan before requesting any implementation authorization.

## Stop conditions

Stop for duplicate identity truth, missing historical continuity, unreconcilable permission behavior, inability to preserve audit attribution, required production credentials, required provider activation, scope expansion, required locked-canon change, or any attempted schema/migration/runtime action.

## Exit evidence

- Inventory and architecture map.
- Threat model.
- Identity/account/actor mapping matrix.
- Permission and relationship enforcement map.
- Session/recovery/revocation analysis.
- Audit/observability matrix.
- Schema/migration/rollback assessment.
- Existing test baseline and gap report.
- Recommended Option B, Option C, or no-change disposition.

## Current authority

Charter prepared only. `W1-RF01` is not open or authorized until a separate founder decision.
