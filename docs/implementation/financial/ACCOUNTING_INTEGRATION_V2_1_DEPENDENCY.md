# Accounting Integration Dependency

QuickBooks and every other accounting system remain projections or adapters under Financial Truth and Responsibility V2.1 and External Architecture V2.0. EquineSync canonical obligations, financial events, reconciliation state and provenance cannot be silently overwritten by an accounting provider.

Any future accounting-integration RF must define legal-entity scope, books and periods, mapping versions, posting authority, idempotency, reversals, reconciliation, failure handling, read/write direction, evidence and disable controls. Write synchronization, provider activation, credentials, schemas, migration and production use remain unauthorized.
