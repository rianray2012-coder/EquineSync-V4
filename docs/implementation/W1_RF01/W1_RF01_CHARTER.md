# W1-RF01 Charter

**RF:** `W1-RF01`  
**Title:** Identity Foundation Readiness and Security Hardening Assessment  
**State:** `AUTHORIZED_FOR_PLANNING_AND_ASSESSMENT`  
**Wave:** `WAVE_1`

## Objective

Establish an evidence-backed identity inventory, threat model, convergence plan, control-plane assessment, migration alternatives, implementation options, and founder decision packet without changing runtime behavior.

## Authority

Read-only repository inspection and governance-document creation are authorized. Runtime implementation, authentication changes, permission changes, schema mutation, migration, provider activation, secrets activity, deployment, production mutation, and launch are not authorized.

## Gates

The RF proceeds through Phases 0-9. A credible P0 stops the affected analysis. Final completion does not grant runtime authority.
