# W1-RF01 Canonical Identity Target State

The target control plane has one canonical account identity for authentication, one durable actor identity for action attribution, explicit person/organization/facility principals, versioned memberships and relationships, permission-model field projection, and provider-neutral authentication adapters.

Authentication proves control of an account. It does not itself prove legal identity, ownership, guardianship, professional status, facility authority, provider scope, or payment responsibility.

Every request resolves:

1. authenticated account and session;
2. selected actor and active organization/facility context;
3. current account, actor, membership, relationship, and authority revisions;
4. domain capability and object relationship;
5. field-level projection;
6. audit attribution and decision correlation.

Legacy `users` fields remain controlled compatibility projections until additive migration and access-delta evidence pass.
