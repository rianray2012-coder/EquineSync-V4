# W1-RF01 Permission Gap Matrix

| Gap | Affected scope | Required proof |
| --- | --- | --- |
| Pending-review role not centrally denied | Marketplace trainer/barn/provider | Negative route matrix before/after remediation |
| Direct checks vs capability map | Product routes | Complete endpoint-to-capability inventory |
| Backend/frontend policy duplication | Navigation and API | Contract-generation or parity tests |
| Single barn role vs memberships | Multi-facility users | Context selection and cross-context denial tests |
| Relationship revocation not session-bound | Guardian/provider/staff | Immediate next-request and refresh denial tests |
| Platform-role provenance incomplete | Admin portal | Assignment, approval, review, and revocation evidence |
| Object-level checks uneven | Horses, medical, financial, minor data | Role/relationship/field projection matrix |
| Delegation not implemented canonically | Future representatives | Scope, expiry, no-redelegation, audit tests |
