# Global Governance V1.0 Post-Lock Change Control

1. Never move, overwrite, or delete the immutable Governance V1.0 tag.
2. Never rewrite the baseline commit or force-push protected history.
3. Changes under `docs/canon/`, `docs/implementation/`, or `docs/governance_v1_0/` require a pull request and designated owner review.
4. A successor baseline must preserve this manifest, lock record, certificate, tag, release, and checksum evidence.
5. Historical manifests remain point-in-time evidence and must not be rewritten to match later mutable registry states.
6. No governance change creates implementation or operational authority unless a separate founder directive grants it explicitly.
