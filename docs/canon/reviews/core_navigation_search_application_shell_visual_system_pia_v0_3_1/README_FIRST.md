## Integrity verification

Use the three-layer model documented in `07_integrity/INTEGRITY_MODEL.md`:

1. Verify the outer ZIP SHA-256 against the supplied sidecar file.
2. Extract once into an empty directory.
3. Confirm the manifest row count equals the full extracted file count.
4. Confirm the manifest path set exactly equals the extracted file path set.
5. Confirm the checksum ledger contains exactly two fewer entries than the full inventory.
6. Confirm the only ledger exclusions are the checksum ledger and package manifest.
7. Verify every checksum-ledger entry.
8. Verify the checksum ledger's actual hash against its package-manifest row.
9. Confirm the package-manifest self row uses `SELF_REFERENCE_EXCLUDED` and is bound by the outer archive hash.
