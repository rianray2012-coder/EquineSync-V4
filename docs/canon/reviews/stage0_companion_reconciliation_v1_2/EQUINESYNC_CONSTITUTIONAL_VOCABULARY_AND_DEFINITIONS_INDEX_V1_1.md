## Revision Note

Version 1.1 updates Media-domain references to the founder-accepted V2.1
successor, adds the new digital-asset vocabulary introduced by the
extended Media canon, and converts several overbroad generic terms into
scoped cross-domain aliases. Adoption or use of this Index does not
change implementation authority.

# 1. Purpose

This Index establishes a single navigable vocabulary layer across the
EquineSync constitutional canon. It consolidates controlling and
cross-domain definitions, identifies the primary constitutional owner of
each term, records related terms, and prevents silent definitional
drift.

This Index does not independently create substantive authority. Where a
definition conflicts with a controlling founder-accepted canon document,
the controlling canon document governs until the conflict is formally
reconciled and this Index is updated.

# 2. Governing Rules

1\. A term has one primary constitutional owner, even when used across
many domains.

2\. Specialized canon controls the specialized meaning of a term within
its domain.

3\. Lower-order implementation artifacts may add narrower technical
detail but may not weaken or silently redefine constitutional meaning.

4\. Provider names, database fields, route names, interface labels, and
legacy schema terms do not become constitutional definitions merely
through use.

5\. Synonyms and aliases must map to the canonical term rather than
create competing meanings.

6\. A term may be authoritative only within a defined scope.

7\. When ambiguity affects safety, welfare, legal rights, privacy,
safeguarding, ownership, finance, evidence, or access, implementation
must pause or apply the more protective rule pending controlled
reconciliation.

8\. Changes require versioning, source identification, affected-document
review, and appropriate constitutional authority.

9\. Generic cross-domain words such as owner, subject, custodian,
revocation, suspension, termination, source record, system of record,
and projection must be interpreted through the scoped term and the
owning constitutional domain.

# 3. Entry Structure

Each entry contains the consolidated Definition, Primary Owner, Related
Terms, and Status. Status identifies whether the entry is canonical, a
cross-domain consolidation, or an alias clarification. Generic aliases
do not override the scoped term owned by specialized canon.

# 5. Interpretation and Maintenance

This Index should be updated whenever a new constitutional document is
founder accepted; a successor changes a controlling definition;
cross-canon reconciliation identifies overlap or conflict;
implementation proposes a term affecting constitutional meaning; an
alias or legacy label risks becoming a competing definition; or a
release introduces a new regulated, safety-sensitive, financial,
evidentiary, AI, media, minor, guardian, or access-control concept.

Each update must preserve prior versions, identify added, revised,
retired, scoped, and aliased terms, record the source authority for
every change, and update successor references without silently changing
the substantive owner of a definition.
