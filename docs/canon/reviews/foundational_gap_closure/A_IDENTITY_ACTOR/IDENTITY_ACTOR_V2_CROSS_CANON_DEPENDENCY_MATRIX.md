## Cycle analysis

No unavoidable authority cycle exists if ownership is explicit. Identity owns durable identity, accounts, actor/principal context, authentication context, and attribution references. Relationship owns representation/delegation/guardian/membership semantics. Permission owns authorization. Claims owns contested procedure. Audit owns audit evidence. External Architecture owns provider boundaries. The candidate’s current “lower-order conflict” language must be removed or replaced with scoped conflict resolution to preserve this acyclic model.
