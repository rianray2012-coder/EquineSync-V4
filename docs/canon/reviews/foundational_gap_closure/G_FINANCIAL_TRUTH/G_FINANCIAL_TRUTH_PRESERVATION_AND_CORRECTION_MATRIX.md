# Financial Truth and Responsibility V2.0 Preservation and Correction Matrix

| Area | Result | Required treatment |
| --- | --- | --- |
| Historical provenance | New document | Preserve creation date and never label recovered or superseding an unknown predecessor |
| Relationship roles | Aligned | Keep payer/payee/owner/guardian/beneficiary/recipient roles distinct |
| Record governance | Aligned | Stewardship remains controlling for retention, legal hold, export, and correction |
| Claims/disputes | Aligned | Dispute and chargeback outcomes remain attributed, not legal adjudication |
| Permissions | Aligned | Financial role never grants unrelated record access |
| Processor truth | Aligned | Provider events are evidence; settlement requires reconciliation |
| Ledger correction | Aligned | Append reversal/replacement; no destructive settled-history edit |
| Tax/legal policy | Incomplete | Founder and qualified review required |
| Approval thresholds | Incomplete | Controlled registry and founder decisions required |
| External providers | Deferred | No credentials, webhooks, connected accounts, or API activity |
| AI | Aligned | Explanation/classification only under RF30; no financial action |
| Implementation | Prohibited | Separate schema, threat, test, migration, and activation gates required |

No source text is silently corrected through this matrix. Material changes require a versioned candidate and founder review.
