# 1. Purpose

This Matrix assigns a primary constitutional owner to material
EquineSync governance subjects, identifies the scope owned by that
authority, names principal supporting and boundary authorities, and
records the anti-drift rule that prevents adjacent canon, implementation
artifacts, technical systems, vendors, or interface behavior from
silently taking control of the subject.

This is a navigation and interpretation artifact. It does not
independently create substantive rights, duties, permissions,
implementation authority, production authority, provider authority, or
public-launch authority. The active controlling version and lifecycle
posture of every referenced family must be resolved through the
Controlled Canon Index and governing founder evidence.

# 2. Constitutional Authority Hierarchy

1\. Applicable law, valid court orders, regulatory duties, and binding
professional restrictions.  
2. Founder directives, constitutional acceptance and adoption decisions,
and recorded locks within their stated scope.  
3. Apex Product Vision and Ecosystem canon.  
4. Controlling specialized constitutional canon for the subject
matter.  
5. Controlled registries, indexes, and reconciliation artifacts that
interpret but do not replace substantive canon.  
6. Locked domain RFs and implementation-governance instruments within
their granted scope.  
7. Authorized implementation atlases, work packages, technical
specifications, tests, and release evidence.  
8. Repository schemas, code, routes, interfaces, operational practices,
and external-provider state.

A lower layer may implement a higher layer but may not amend, waive,
contradict, or broaden it.

# 3. Interpretation Rules

Primary owner. One constitutional family owns the substance of a subject
even when many canons apply.  
  
More specific and more protective. Equally protective provisions are
applied through the more specific canon; compatible overlapping rules
are applied at the more protective privacy, safeguarding, security,
evidentiary, welfare, or permission level.  
  
Overlay discipline. AI, reporting, media, plugin, integration, security,
and operational canons govern their layer but do not take ownership of
the underlying legal, financial, medical, welfare, relationship, or
record decision.  
  
No authority by silence or capability. A database field, role label,
administrator console, API, vendor feature, model output, file location,
or existing code path does not create constitutional authority.  
  
Stop and reconcile. Implementation pauses when ambiguity materially
affects safety, welfare, minors, privacy, legal rights, ownership,
finance, evidence, retention, or access.  
  
Newest-version resolution. Family references resolve to the active
controlling substantive successor recorded in the Canon Index; a version
suffix alone is not proof of lifecycle status.  
  
Founder-designated version exception. The Security Foundational Models
V1.0 package is an express founder exception to the default
newest-version rule. Its three identified V1.0 artifacts control within
their stated and reconciled scope until the Founder expressly supersedes
them. A higher version number, later narrative reference, or later
candidate does not supersede the package by number alone.

# 4. Matrix Field Guide

Primary Constitutional Authority identifies the family that owns the
core rule and final subject-matter interpretation. Authority Scope
describes what that family governs. Supporting / Boundary Authorities
identify canons that constrain, evidence, implement, or apply the
primary rule. Boundary / Precedence Rule states the principal limit or
conflict rule.

# 8. Maintenance Triggers

Update this Matrix when a new constitutional family is created, a
successor is founder accepted, a domain boundary changes, a cross-canon
conflict is reconciled, a legacy implementation attempts to claim
authority, a new protected or regulated subject is introduced, or an
implementation RF identifies a subject with no clear owner. Each update
should preserve prior versions and record added, reassigned, narrowed,
broadened, retired, and unresolved rows.

# 9. Authority Boundary

Creation or founder acceptance of this Matrix does not authorize schema
creation, code changes, migrations, permission changes, external
processing, provider activation, AI activation, live payments,
production mutation, public sharing, public trust claims, customer
onboarding, or launch. It is a constitutional navigation, ownership, and
precedence artifact only.
