# Completeness, Reliability, and Evidence Classifications

## Completeness

- C0: Not started
- C1: Partial
- C2: Substantially complete
- C3: Complete for recorded scope with limitations
- C4: Complete for recorded scope
- C5: Complete and independently verified for recorded scope

## Reliability

- R0: Unassessed
- R1: Single-agent result
- R2: Internally checked
- R3: Independently verified
- R4: Independently re-performed
- R5: Cross-method or cross-environment corroborated

## Evidence sufficiency

- E0: No supporting evidence
- E1: Reported evidence
- E2: Single-source evidence
- E3: Corroborated evidence
- E4: Directly verified evidence
- E5: Independently re-performed evidence

## Reproduction levels

- Level 0: Not executed
- Level 1: Single-run completion
- Level 2: Repeat-run completion
- Level 3: Separate-controller reproduction
- Level 4: Cross-environment reproduction

These classifications support, but never automate, Founder judgment.
