# Phase 1 Manual Procedurally Segregated Review Package

Version `1.0.0` implements the Founder-authorized documentary, configuration, deterministic-validation, synthetic-test, and evidence controls for manual procedurally segregated internal AI review. It does not activate the ES-RA roles, implement provider orchestration, integrate MIAP, authorize production activity, or issue a Founder decision.

Start with `PHASE_1_AUTHORITATIVE_BASELINE_DETERMINATION.md`, `PHASE_1_SOURCE_INVENTORY.md`, `PHASE_1_PROGRAM_CHARTER.md`, and `PHASE_1_REVIEW_EXECUTION_RUNBOOK.md`. Machine-readable role profiles are in `profiles/`; deterministic utilities are in `scripts/`; Pilot A materials are in `pilot_a/`; generated evidence is in `evidence/`.

The truthful package disposition is recorded in `PHASE_1_FOUNDER_REVIEW_PACKAGE.md` after validation.
