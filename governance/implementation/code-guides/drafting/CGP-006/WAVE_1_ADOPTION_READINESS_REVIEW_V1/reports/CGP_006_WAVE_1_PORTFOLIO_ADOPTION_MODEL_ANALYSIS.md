# CGP-006 Wave 1 Portfolio Adoption Model Analysis

**Recommended model:** `CONDITIONAL_PORTFOLIO_ADOPTION`
**Determination:** `CGP_006_WAVE_1_ADOPTION_READINESS_REVIEW_COMPLETE_READY_FOR_CONDITIONAL_ADOPTION_DIRECTIVE`

The evidence supports conditional portfolio adoption rather than unconditional adoption, guide-by-guide adoption, or deferred adoption.

## Dependency Order

1. `ES-CG-00`
2. `ES-CG-01`
3. `ES-CG-13`
4. `ES-CG-10`

Adopting later guides without the upstream guide conditions would create terminology, authority, and evidence-governance gaps. A phased adoption may be considered only if each phase preserves the portfolio-wide warning covenant, source-boundary covenant, and GAP-0004 activation/implementation conditions.

## Conditions Applying To All Guides

- `CGP006-AR-COND-0001`: retained warning covenant.
- `CGP006-AR-COND-0002`: GAP-0004 pre-activation condition.
- `CGP006-AR-COND-0003`: implementation-mapping authority condition.
- `CGP006-AR-COND-0004`: implementation authority and evidence condition.
- `CGP006-AR-COND-0005`: source-boundary covenant.

## Consequence Of Partial Adoption

Partial adoption is not recommended unless the adopted subset preserves dependency order and carries all portfolio-wide conditions. Otherwise, authority gaps and inconsistent activation conditions would result.
