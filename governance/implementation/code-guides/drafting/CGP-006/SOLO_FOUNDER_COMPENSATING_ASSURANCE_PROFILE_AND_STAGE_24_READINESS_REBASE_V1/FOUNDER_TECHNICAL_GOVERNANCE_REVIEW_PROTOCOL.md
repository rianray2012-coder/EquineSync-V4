# Founder Technical Governance Review Protocol

**Review type:** `FOUNDER_TECHNICAL_GOVERNANCE_SELF_REVIEW_WITH_DISCLOSED_NON_INDEPENDENCE`

## Protocol Requirements

1. Freeze exact guide bytes before review.
2. Close authoring phase before review starts.
3. Identify review phase separately from remediation.
4. Prohibit silent editing during review.
5. Record findings before remediation.
6. Perform remediation only in a separate authorized phase.
7. Reopen review after changed bytes.
8. Preserve complete non-independence disclosure.

## Review Areas

Authority fidelity, implementability, architecture neutrality, terminology, control clarity, invariant completeness, testability, evidence feasibility, failure behavior, recovery behavior, dependency treatment, exception treatment, maintainability, scope boundaries, repository-reality conflicts, and cross-guide conflicts.
