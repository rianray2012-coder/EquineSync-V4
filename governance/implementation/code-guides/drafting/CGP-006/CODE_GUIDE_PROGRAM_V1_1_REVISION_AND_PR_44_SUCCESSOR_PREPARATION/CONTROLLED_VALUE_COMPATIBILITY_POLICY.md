# Controlled Value Compatibility Policy

Historical records retain their original values unless a separate authorized migration edits that record. New V1.1 records use the V1.1 controlled values. Ambiguous legacy values are not automatically migrated and require reviewed disposition.

Classification meanings: `DIRECT_EQUIVALENT`, `CONTEXTUAL_EQUIVALENT`, `SPLIT_INTO_MULTIPLE_V1_1_VALUES`, `HISTORICAL_ONLY`, `NO_SAFE_AUTOMATIC_MAPPING`, and `FOUNDER_DECISION_REQUIRED`.
