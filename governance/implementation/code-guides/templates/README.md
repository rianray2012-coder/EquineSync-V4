# Code Guide Templates

Templates define reusable structure for future guide drafting, control definition, invariant definition, review, decisions, accession, blocked receipts, and change impact reports.

## Use

Each future guide prompt should copy the relevant template, fill in stable IDs, cite source authority, record retained gaps, and keep activation boundaries explicit.

## Boundary

CGP-002 templates are generic. They do not create EquineSync product requirements or guide-specific controls.
