
# Program Dependency Waves

CGP-001 records the initial high-level dependency approach only. It does not create control-level dependencies.

## Wave 1

- `ES-CG-00` establishes the charter location.
- `ES-CG-01` depends on `ES-CG-00`.
- `ES-CG-13` depends on `ES-CG-00` and `ES-CG-01`.
- `ES-CG-10` depends on `ES-CG-13` and the authority structure of `ES-CG-00` and `ES-CG-01`.

## Later Waves

- Wave 2 depends on the Wave 1 foundation reaching at least `SCENARIO_VALIDATED` unless separately authorized.
- Wave 3 depends on relevant Wave 2 guides.
- Wave 4 depends on relevant Waves 1 through 3.
- Wave 5 depends on relevant Waves 1 through 4.

Detailed dependency rules remain reserved for later authorized prompts.
