
# Non-Authorization Boundary

**Prompt ID:** `CGP-001`
**Directive ID:** `ES-DIR-CGP-001-CODE-GUIDE-PROGRAM-INITIALIZATION-2026-07-25`

CGP-001 authorizes documentary repository scaffolding and tracking initialization only.

It does not authorize:

- substantive Code Guide controls;
- application source code changes;
- tests outside `governance/implementation/code-guides/validation/tests/`;
- `.github/workflows/` changes;
- PR #3 or CI branch modification;
- approved PIA changes;
- implementation atlas changes;
- Founder decisions;
- guide adoption or active status;
- pull request creation;
- merge, branch-protection, release, deployment, pilot, production, financial, messaging, AI, moderation, archival, or enrollment actions.

Any ambiguity requiring product policy or Founder authority must be recorded and left unresolved until separately authorized.
