
# CGP-001 Controlled Values

CGP-001 documents the controlled values needed for initialized registers. These values do not create substantive Code Guide controls.

## Guide Maturity States

`PLANNED`, `CHARTERED`, `SOURCE_FROZEN`, `CURRENT_STATE_ASSESSED`, `DRAFTING`, `INTERNAL_REVIEW`, `TECHNICAL_REVIEW`, `PRODUCT_REVIEW`, `CROSS_GUIDE_REVIEW`, `ADVERSARIAL_REVIEW`, `SCENARIO_VALIDATED`, `ASSURANCE_REVIEW`, `ADOPTION_CANDIDATE`, `ADOPTED`, `REPOSITORY_ACCESSIONED`, `ACTIVE`, `REVISION_PENDING`, `SUPERSEDED`, `RETIRED`, `BLOCKED`

## Prompt Status Values

`NOT_ISSUED`, `ISSUED`, `IN_PROGRESS`, `RETURNED`, `ACCEPTED`, `REVISION_REQUIRED`, `BLOCKED`, `SUPERSEDED`

## Evidence Status Values

`NOT_REQUIRED`, `PLANNED`, `PARTIAL`, `COMPLETE`, `VERIFIED`, `STALE`, `INVALID`, `MISSING`

## Finding Severities

`P0`, `P1`, `P2`, `P3`

## Mapping States

`IMPLEMENTED`, `PARTIALLY_IMPLEMENTED`, `PLANNED`, `MISSING`, `CONFLICTING`, `NOT_APPLICABLE`

## Adoption States

`NOT_ADOPTED`, `APPROVED_FOR_CONTROLLED_ADOPTION`, `APPROVED_WITH_RETAINED_GAPS`, `REVISION_REQUIRED`, `BLOCKED_PENDING_DECISION`, `REJECTED`, `SUPERSEDED`

## Accession States

`NOT_ACCESSIONED`, `ACCESSION_PENDING`, `REPOSITORY_ACCESSIONED`, `CUSTODY_GAP`, `SUPERSEDED`

## Work Package States

`NOT_STARTED`, `IN_PROGRESS`, `RETURNED`, `BLOCKED`, `SUPERSEDED`

## Artifact Status Values

`PLANNED`, `CREATED`, `REMOTE_VERIFIED`, `SUPERSEDED`, `RETIRED`, `BLOCKED`

## Review and Decision Status Values

`OPEN`, `CLOSED`, `DEFERRED`, `BLOCKED`, `NOT_REQUIRED`

## Placeholder Validator Status

`NOT_IMPLEMENTED_CGP_002_REQUIRED`
