# EquineSync Founder-Orchestrated Reviews

The EquineSync Founder-Orchestrated Review Agent Framework V1.3 is Founder approved and controls all EquineSync Founder-Orchestrated Reviews.

Before review work, read `governance/founder_orchestrated_review/agent_config/V1.0.0/orchestration/CODEX_ORCHESTRATION_DIRECTIVE.md` and `governance/founder_orchestrated_review/agent_config/V1.0.0/shared/COMMON_AGENT_OPERATING_CONTRACT.md`.

A Founder Review Authorization and a uniquely identified, frozen package are mandatory before substantive review begins. Use the separate registered agents under `.codex/agents/`; one agent may not impersonate multiple roles.

Before every agent spawn, read and apply `governance/founder_orchestrated_review/RUNTIME_PERMISSION_CONTROL.md`. Record the parent permission mode and live overrides, compare them with the role matrix, and stop before delegation on any missing record or unauthorized mismatch. Formal review cycles default to read-only; danger-full-access, unrestricted, or `--yolo` operation is prohibited unless Rian Ray expressly authorizes a documented exception.

Agent outputs are recommendations and evidence, not final decisions. Only Rian Ray may approve, adopt, constitutionally lock, waive requirements, accept risk, authorize implementation, authorize pilot operation, authorize release or production, or issue final Founder disposition.

Do not begin a substantive review cycle during installation or configuration validation. Package drift or any post-freeze change requires a new package version, a recorded change, affected-reviewer notice, and rerun analysis under the detailed package controls.
